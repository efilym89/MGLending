# AGENTS.md — MGLending

## Что это
Лендинги ANNAELLE (главная + вакансии) для Tilda-блока T123; описание — в `README.md`.

## Где работает
GitHub Pages этого репозитория: `https://efilym89.github.io/MGLending/` (ветка `main`, корень). Сайт в Tilda подтягивает отсюда CSS/JS. **Слияние в `main` = выпуск на живую страницу.**

## Ветки и выпуск
`main` — боевая и по умолчанию. Остальные ветки (`codex/…`, `migration/…`, `backup/wip-…`) — резервные, не удалять. Правки — только веткой `claude/<тема>-<дата>` и PR; слияние в `main` — только по слову владельца. После правки главной — `node build-tilda.cjs` (пересобирает `tilda-t123.html`); при смене предложений обновить версии кэша вместе (см. `README.md`).

## Чего нельзя
- **Репозиторий публичный:** ни ключей, токенов, адресов серверов, персональных данных соискателей и клиентов. Адрес приёма заявок — только публичный endpoint; секреты — на стороне сервера.
- Не менять цены, предложения и условия вакансий без владельца; не ломать форму заявки и Meta Pixel.
- Force-push, смена видимости и ветки по умолчанию, удаление веток — только владелец.
